# Journaler

## What is this?

This is a custom form-making app designed to be answered repeatedly by the user. It's useful for making daily check-ins, food logs, etc.

Currently, this app's basic functions are working, but more features are planned.

This app is now deployed to the web! Try it [here](https://journaler.expo.app).

## Where is the app's data stored?

The app stores all user-generated information directly on the device using SQLite.

## What tools were used to make this?

This app was made with Expo.dev, in TypeScript, JavaScript, and SQL, and was made with Claude Code.
